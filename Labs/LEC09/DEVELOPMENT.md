# 소닉 스프라이트 뷰어 개발 및 검증 기록

## 실행 방법

Python과 pico2d가 설치된 환경에서 다음 명령을 실행한다.

```powershell
python -m pip install pico2d
python sonic_sprite_viewer.py
```

두 번째 명령은 `Labs/LEC09`에서 실행한다. 다른 폴더에서는 실행 파일 경로를 지정해도 되며, 이미지 경로는 실행 파일 위치를 기준으로 결정된다. `sonic-sprite.png`는 실행 파일과 같은 폴더에 둔다. 창 닫기 또는 Escape로 종료한다.

## 확정한 구현 값

- 실행 코드: `sonic_sprite_viewer.py` 한 파일
- 화면: 800×600픽셀 (사용자의 화면 크기 변경 커밋 반영)
- 표시: 원본 비율 유지, 8배 확대, 발밑 높이 220픽셀 기준. 제자리 동작은 가로 중앙에 표시하며 이동 동작은 화면 안에서 왕복한다.
- 프레임 간격: 0.1초, 초당 10프레임
- 각 동작: 정확히 5회 반복 후 마지막 프레임으로 1초 대기
- 전체 순환: 52초, 종료 입력 전까지 무한 반복
- 재생 및 대기 중 모두 이벤트 처리

## 검증 결과

아래 자동 검증 결과는 이동 기능 추가 전의 1200×800 버전 기록이다. 현재 800×600 화면과 이동 기능은 사용자가 직접 테스트하며, 이번 변경에서 자동 테스트 및 실행 검증은 수행하지 않았다.

2026-10-05 기준, 제공된 Python 실행 환경에서 pico2d 1.5.1 및 PySDL2 0.9.17로 검증했다. 기본 `py` 실행기는 설치된 Python을 찾지 못하므로, 로컬에서 위 명령을 사용하려면 Python 설치 환경이 필요하다.

| 항목 | 결과 |
| --- | --- |
| Python 문법 검사 | 통과 |
| 전체 동작 및 좌표 검사 | 14개 동작, 76프레임 모두 이미지 내부이며 잘라낸 영역의 불투명 경계가 일치 |

자동 검증은 화면 없는 SDL 가상 드라이버에서 수행했다. pico2d 1.5.1이 해당 환경에서 가속 렌더러 생성에 실패한 뒤 소프트웨어 렌더러로 전환하지 못하므로, 검증 도구에서만 소프트웨어 렌더러를 지정했다. 제품 코드는 변경하지 않았다. 실제 데스크톱 창에서 체감 재생 속도와 그래픽 드라이버 동작은 별도 수동 확인 항목이다. 2회 순환은 실제 104초를 기다리는 대신 가상 시계로 검증했다.

## 화면 이동 기능 추가

제자리 재생만으로는 이동 동작을 확인하기 어려워, 동작별 위치 변화와 방향 반전을 추가했다. 문서 요구사항은 `8d66296` 커밋에 반영했다.

| 동작 | 수평 이동 속도 | 표시 방식 |
| --- | --- | --- |
| 걷기 | 120픽셀/초 | 좌우 왕복 |
| 달리기 | 200픽셀/초 | 좌우 왕복 |
| 회전 | 180픽셀/초 | 좌우 왕복 및 반복마다 상승·하강 |
| 공 형태 회전 | 240픽셀/초 | 좌우 왕복 |
| 빠른 달리기 | 320픽셀/초 | 좌우 왕복 |
| 질주 | 400픽셀/초 | 좌우 왕복 |
| 피격 | 160픽셀/초 | 오른쪽에서 왼쪽으로 출발, 시선은 이동 방향 반대 |
| 나머지 동작 | 0 | 중앙에서 제자리 재생 |

이동 범위는 동작 내 최대 프레임 너비의 절반과 화면 여백 24픽셀로 계산한다. 경계에서는 이동 방향과 시선을 반전한다. 회전의 상승 높이는 최대 100픽셀이며, 최대 프레임 높이와 화면 위 여백을 고려해 제한한다.

이동 시간은 재생 상태에서 계산하므로 별도 위치 누적에 따른 오차를 피한다. 5회 재생 후 대기 중에는 완료 시점의 위치와 방향을 유지하며, 회전은 발밑 기준 높이로 돌아온다. 다음 동작은 초기 위치에서 시작한다. 기존 반복 횟수와 대기 시간은 유지한다.

### 사용자 수동 확인 항목

- 걷기·달리기·질주에서 화면상의 위치가 바뀌고 속도 차이가 보이는지 확인한다.
- 양쪽 경계에서 방향과 시선이 바뀌고 이미지가 잘리지 않는지 확인한다.
- 회전이 반복마다 위로 솟았다 내려오며, 화면 위로 잘리지 않는지 확인한다.
- 피격은 바라보는 방향의 반대로 밀리는지 확인한다.
- 5회 완료 후 1초 동안 마지막 프레임의 위치와 방향이 유지되는지 확인한다.
- 다음 이동 동작은 초기 위치에서, 제자리 동작은 중앙에서 시작하는지 확인한다.
- 전체 순환과 창 닫기·Escape 종료가 동작하는지 확인한다.

자동 테스트 및 뷰어 실행은 사용자 요청에 따라 수행하지 않았다. 위 항목의 실행 결과는 아직 확인되지 않았다.
