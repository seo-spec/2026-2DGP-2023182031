# LEC10 입력 뷰어 개발 기록

## 실행 방법

Python과 pico2d가 설치된 환경에서 `Labs/LEC10_HandlingInputs`로 이동한 뒤 실행한다.

```powershell
python move_charcter_viewer.py
```

`animation_sheet.png`와 `TUK_GROUND.png`를 실행 파일과 같은 폴더에 둔다. 이미지 경로는 실행 파일 위치를 기준으로 계산하므로 다른 폴더에서도 실행 파일 경로를 지정해 실행할 수 있다.

## 구현 결과

- 실행 코드: `move_charcter_viewer.py` 한 파일
- 화면: 800×600, 배경을 화면 전체에 표시
- 초기 상태: 중앙 위치, 오른쪽 IDLE
- 스프라이트: 802×402, 100×100 셀, 네 동작 각각 8프레임
- 표시: 원본 비율을 유지한 1.5배 확대, 표시 셀 150×150
- 이동: 방향키, 초당 200픽셀, 대각선 정규화 및 반대 키 상쇄
- 애니메이션: 프레임 간격 0.1초, IDLE/이동 상태 및 좌우 방향에 맞는 행 선택
- 세로 이동과 정지 시 마지막 좌우 방향 유지
- 경계: 셀 전체를 기준으로 중심 좌표를 가로 75~725, 세로 75~525로 제한
- 경계에 막혀 위치가 변하지 않으면 IDLE 전환; 이동 가능한 다른 축은 계속 이동
- 상태나 방향이 바뀌면 첫 프레임부터 재생
- 포커스 변경 시 눌린 키 초기화; 창 닫기 및 Escape 종료
- 이미지 누락·로딩 실패·프레임 범위 오류 메시지와 캔버스 정리

실제 시트의 위에서 아래 순서는 오른쪽 IDLE, 왼쪽 IDLE, 오른쪽 이동, 왼쪽 이동이다. 이미지 높이가 402픽셀이므로 pico2d의 왼쪽 아래 기준 행 좌표는 302/202/102/2를 사용한다. 기존 실습 파일의 좌표를 그대로 복사하지 않고 이미지 크기와 행 구성을 확인해 정의했다.

## 사용자 수동 확인

사용자 요청에 따라 자동 테스트와 프로그램 실행을 수행하지 않았다. 아래 항목은 모두 **실행 확인 대기**이며, 통과 결과가 아니다.

- [ ] 배경이 표시되고 중앙에서 오른쪽 IDLE이 반복된다.
- [ ] 각 방향키를 누르는 동안 움직이며, 놓으면 해당 축 이동이 멈춘다.
- [ ] 반복 KEYDOWN으로 속도가 누적되지 않고 대각선 속도가 직선과 같다.
- [ ] 반대 방향키를 동시에 누르면 해당 축 이동이 상쇄된다.
- [ ] 좌우 이동의 애니메이션 방향이 맞고 세로 이동·정지 시 마지막 방향이 유지된다.
- [ ] 네 변과 모서리에서 셀 전체가 화면 안에 남고 더 진행하지 않는다.
- [ ] 경계에 막히면 IDLE이 되며, 경계를 따라 움직일 때는 이동 애니메이션이 나온다.
- [ ] 상태와 방향을 바꿀 때 첫 프레임부터 재생한다.
- [ ] 다른 창으로 전환했다 돌아와도 키 입력이 남지 않는다.
- [ ] 이동/정지 중 Escape와 창 닫기로 종료한다.
- [ ] 다른 작업 폴더에서 실행해도 이미지 경로가 맞는다.
- [ ] 이미지 파일이 없을 때 파일명과 오류 메시지를 출력한다.
